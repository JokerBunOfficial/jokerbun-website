JOKERBUN WEBSITE — QUICK START

Included:
- index.html: responsive one-page website.
- assets/jokerbun-mascot.jpg: your original uploaded JokerBun mascot image, included unchanged.

The website uses your original mascot image in the hero section. It does not connect to wallets or request seed phrases/private keys.

Publish:
1. Extract this ZIP.
2. Upload index.html and the assets folder (including jokerbun-mascot.jpg) to the ROOT of your GitHub repository.
3. Commit the files.
4. In repository Settings > Pages, set deployment from the main branch and root folder, then save.
5. Wait for GitHub Pages to publish the site.

Before publishing, verify the contract address and all social links.
